There are two different 'link' tags needed for the navbar, but they both fulfill the purpose of linking CSS styles to the html, so that the 'body' section knows what to look like.

The first 'link' is accessing an online CSS file for more detailed formatting such as font and spacing -- it's accessing a css style called "font awesome".

The second 'link' is accessing the local CSS file that I've made, which impacts more general parts of the navbar's design.
