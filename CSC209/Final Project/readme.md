# CSC 209: Final Project

> By Vivian Streber


### What is this project?

This is a `notetaker` app intended for everyday use. It's designed with a chill atmosphere and clean usability in mind.

#### Some noteable features include:
- Automatic saving function when switching between notes
- Adding, deleting, and saving notes manually
- Customizable naming of notes
- Extensive formatting options within each note (all saved!)
- Privacy - admin cannot see your notes, only your logtimes and how long each user session is in minutes.

### How to use?

There are two versions of the project: the DEMO and the FULL.

#### You can access the demo without a login - it only features one user, and shows how the notes app functions.
